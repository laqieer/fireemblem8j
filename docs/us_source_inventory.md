# US source inventory -- portable-source ceiling

_Generated by `scripts/us_source_tracker.py`. Do not edit by hand._

Every US function symbol in `../fireemblem8u/fireemblem8.map` is
classified by the **US source kind** of its address (the authoritative
cut) from the object section ranges (` .text 0x08ADDR 0xSIZE <obj>`),
then crossed with THIS repo's byte-matched set (text symbols in the
linked `src/*.o`). This establishes the reference decomp's
**US-C-portable** planning ceiling --
the US decomp keeps `asm/arm.o`/`asm/arm_call.o` as descriptive `.s`
(already its gold standard) and links libc/libgcc from `tools/agbcc`,
none of which can ever become matching C.
