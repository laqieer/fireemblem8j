# FE8 JP (Seima no Kouseki) message control tokens.
#
# Maps a [Token] name to one or more u16 symbol values. Single-value tokens are
# also used by the dumper (msg_jp.py) to pretty-print the low control codes;
# multi-value / face-control sequences are dumped as raw [$XXXX] tokens instead,
# so the round-trip stays unambiguous. The engine codes are shared with the US
# ROM (../fireemblem8u/texts/textdefs.txt); only the text payload is CP932.
